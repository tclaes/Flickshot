Select. Mark up. Copy.

Flickshot is a tiny screenshot and annotation tool that lives in your menu bar. Built natively for Apple Silicon, no Rosetta required.

Download for Mac View source

Free & open source (MIT) · Apple Silicon · macOS 14 or later

Why Flickshot

The quick-capture workflow you know, rebuilt for M-series Macs.

Press a shortcut, drag a rectangle, scribble on it, and it is on your clipboard. Nothing to upload, no account, no Intel binary running through Rosetta.

Native arm64

Written in Swift with AppKit and ScreenCaptureKit. Starts instantly and stays light in the menu bar.

One shortcut away

⌥⌘S from anywhere. Drag, annotate, press Return. Done in a couple of seconds.

Stays on your Mac

Screenshots go to your clipboard or a file you choose. No cloud uploads, no tracking. MIT licensed.

Everything you need to mark it up

Seven tools in a compact toolbar right next to your selection. Hold ⇧ to snap lines to 45° and keep shapes square.

Shortcuts

Keep your hands on the keyboard.

Every action has a shortcut, and scrolling over a selection changes the line width.

Take screenshot
⌥⌘S or the menu bar icon
Select area
Drag, with ⇧ for a square. Click once or press ⌘A for the whole display
Move / resize
Drag inside the selection with no tool active, or drag the handles
Line width
Scroll wheel or two-finger scroll while a selection is showing
Copy
⌘C, ↩, or double-click the selection
Save
⌘S
Undo
⌘Z
Cancel
esc or right-click

Install

Get Flickshot.

Requires an Apple Silicon Mac (M1 or newer) running macOS 14 Sonoma or later.

Build from source · recommended

Needs the Xcode Command Line Tools. The script builds the app, copies it to /Applications and launches it.

$ git clone https://github.com/tclaes/Flickshot.git
$ cd Flickshot
$ ./build.sh install

Prebuilt download

Zipped builds are attached to each GitHub release. They are not notarized by Apple, so macOS may ask you to confirm before opening.

On first launch, allow Screen & System Audio Recording in System Settings → Privacy & Security.
